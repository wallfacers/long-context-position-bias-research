# Qwen2.5-7B 单 seed 位置偏差消融 pilot

状态基准：2026-08-26。本文档固定本轮 pilot 的问题、设计、统计口径和结论边界；最终数值只从完整 test 逐样本结果生成，不能用训练 Loss 或 dev gate 代替。

## 研究目的

现有工作已经证明长上下文位置偏差存在，也展示了位置均衡训练、位置蒸馏和证据图数据的收益，但仍有三个适合用小规模可复现实验补充的空白：

1. 许多结果偏重平均准确率或单跳检索，没有把最弱位置、七位置最大—最小差距和首尾保持情况同时作为结果；
2. 位置配对的数据组织与显式证据引用监督常被一起引入，较少在同一训练和评测协议下做 `2×2` 拆分；
3. 最新闭源 API 模型的评测难以完整复现，而小型开放权重模型更适合发布逐样本预测、输入哈希、环境和成本。

因此，本轮只回答一个有限问题：在 `Qwen2.5-7B-Instruct` 上，跨位置配对训练和证据引用监督是否能在未参与训练的合成长上下文样本上提高答案与证据正确率、改善最弱位置并缩小位置差距，而且不是通过降低首尾准确率或破坏 JSON 格式换取。

这是一轮方向筛选，不声称代表全部模型、自然文档或最终统计显著性。背景证据与论文入口见[文献综述](literature-review.md)和[论文索引](papers.md)。

## 数据与处理条件

数据由确定性规则本地生成，不使用 DeepSeek 或其他 teacher API。答案、证据 ID 和精确短引用都可由程序判定；同一位置等价组保持事实、问题和 filler 不变，只移动目标证据。

四个 QLoRA 条件使用相同的 1,000 条序列预算和近似相同的输入 Token 预算：

| Run | 训练事实组织 | Completion 监督 |
|---|---|---|
| `paired_evidence` | 250 个事实各取 0/25/50/100% 四个位置 | 答案、证据 ID、精确引用 |
| `paired_answer` | 与 `paired_evidence` 完全相同的输入 | 答案；证据数组为空 |
| `independent_evidence` | 1,000 个互不重复事实，各取一个均衡位置 | 答案、证据 ID、精确引用 |
| `independent_answer` | 与 `independent_evidence` 完全相同的输入 | 答案；证据数组为空 |

所有训练条件只含 8K、neutral filler、KV 与聚集式两跳任务。测试矩阵为：

```text
5 runs × 2 tasks × 3 fillers × 2 lengths × 7 positions × 50 groups
= 21,000 predictions
```

- runs：base 加上四个 QLoRA 条件；
- tasks：KV、two-hop；
- fillers：neutral、same-format、answer-bearing；
- lengths：8K、32K；
- positions：0%、10%、25%、50%、75%、90%、100%；
- 每个 run 4,200 个样本，即 600 个位置等价组。

正式 test 的生成上限为 176 Token。128-Token 预跑显示，两跳条件中存在答案与引用已完成但在 `confidence` 或 JSON 闭括号前被截断的样本，因此 128 会把输出预算伪影混入格式和任务失败。test 最长 prompt 为 32,581 Token，32,768 窗口只剩 187 Token；176 在为 vLLM 留出 11 Token 安全余量的同时，足以补齐正常两跳 JSON。持续罗列无关 filler 的异常长输出仍会被截断并判为失败。

32K、same-format、answer-bearing 以及 10/75/90% 位置不参与训练，可用于诊断长度、干扰和未见位置上的迁移。train/dev/test 按原始事实隔离，清单中的逐文件 SHA-256 是输入身份的权威记录。

## 预先固定的结果口径

主要报告：

- 平均答案准确率；
- 平均最弱位置准确率：先在每个 `task × filler × length` 条件内取七位置最小值，再对条件等权平均；
- 平均位置差距：同样先计算条件内 `max(position accuracy) - min(position accuracy)`；
- 首尾平均准确率与中间位置准确率；
- JSON 有效率；
- 证据 ID、精确引用和预测引用可支持率。

所有位置比较按 `group_id` 配对。95% 区间来自按 `task × filler × length` 分层的 2,000 次位置等价组 bootstrap，随机种子固定为 `20260825`，并保存每次抽样索引。分析包含：

- 每个 QLoRA 条件相对 base 的配对效应；
- `paired - independent` 主效应；
- `evidence - answer` 主效应；
- pairing 与 supervision 的交互项；
- 每个统计量族内的 Holm 多重比较校正。

bootstrap p 值在本轮只作探索性筛选信号。单训练 seed 不能支持跨 seed 的最终显著性结论。

## 探索性通过标准

一个条件只有同时满足以下工程门槛，才标记为值得进入多 seed 主实验：

- 相对 base 的平均位置 gap 至少降低 50%；
- 平均最弱位置准确率至少提高 10 个百分点；
- 平均答案准确率下降不超过 2 个百分点；
- 首尾平均准确率下降不超过 2 个百分点；
- JSON 有效率至少 99%。

证据监督是否有效另外依据证据 ID/引用正确率及其区间判断，不能只用答案正确率替代。训练 completion Loss 接近零只触发过拟合审计，不构成通过证据。

## 结论边界与已知混杂

- `answer-only` 与 `evidence-supervised` 在各自 pairing 层内共享完全相同的输入，适合估计“改变监督目标”的处理效应；两者 completion 长度不同，因此绝对训练 Loss 不可横向比较。
- 为保持序列和输入 Token 预算相同，paired 条件覆盖 250 个独立事实，independent 条件覆盖 1,000 个独立事实。因此 pairing 对比同时改变了“同一事实跨位置重复”和“事实多样性”，不能单独归因为配对这一条机制。
- 数据是可验证的合成 KV/两跳任务，不覆盖无字面重合语义检索、自然文档、代码、分散式多跳或 64K/128K。
- 量化 QLoRA 和 GPU 内核不保证逐 bit 一致；可复现目标是输入、模型 revision、adapter、代码和抽样索引的哈希可验证，以及统计上等价的结果。
- 若筛选成功，下一阶段至少需要三个训练/数据 seed、自然语义和对抗数据、更多模型，并单独控制 paired 条件的事实多样性。

## 产物与验收

完成产物必须包括五份逐样本 JSONL、每 run 身份元数据、84 个条件格的聚合表、配对 bootstrap 索引、效应量与区间、PNG/SVG 论文图、GPU 遥测、依赖与硬件记录、验证报告、总包 SHA-256、时间和人民币成本。

评测和后处理脚本不得调用关机。主代理必须先验证 21,000 条结果、生成统计与图表、校验压缩包并向用户汇报，最后才单独执行 AutoDL 关机。
