## 三、回家操作手册

### 1. AutoDL 开机并确认 SSH

控制台开机后，以控制台显示的 SSH 命令为准（同实例通常仍是
`ssh -p 12078 root@connect.westb.seetacloud.com`，密码登录）。
建议在家里的 `~/.ssh/config` 加别名：

```
Host autodl-pbias
    HostName connect.westb.seetacloud.com
    Port 12078
    User root
```

（端口若变化以控制台为准；脚本全部走 `autodl-pbias` 别名。）

### 2. 克隆代码 + 拉取上传（一条链）

```bash
git clone git@github.com:wallfacers/long-context-position-bias-research.git
cd long-context-position-bias-research
export HF_TOKEN=hf_...   # 今天发给代理的那个 token
bash scripts/pull_hf_release.sh --upload
```

脚本自动完成：
1. 4 路并行 rsync（adapters 两家族 + results + paper，断点续传）
2. 校验远端/本地文件数与字节数（不齐会拒绝上传并让你重跑）
3. `upload_large_folder` 分块断点续传到 HF 私有仓
   （无 `.venv` 时自动用 `python3` 并 `pip install --user huggingface_hub`）

预期耗时：rsync 1.5-2h（AutoDL 出口带宽 ~50MB/min 上限）+ 上传 0.5-1h。

### 3. 验证

HF 仓库页面应出现 `adapters/`（36 × checkpoint-96）、`results/`、`paper/`、
`README.md`；或：

```bash
python3 -c "
from huggingface_hub import list_repo_files
import os
fs = list_repo_files('wallfacers/position-bias-strict-block96',
                     repo_type='dataset', token=os.environ['HF_TOKEN'])
print(len(fs), 'files')"
```

（应 > 900 个文件。）
