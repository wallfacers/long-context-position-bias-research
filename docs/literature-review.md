# 文献综述：长上下文模型的位置偏差

更新时间：2026-08-29。论文入口均指向 alphaXiv，正文判断仅来自已认证 MCP 返回的论文页面。

## 结论摘要

现有证据支持“位置相关的上下文利用失败仍然存在”，但不支持“所有长上下文模型总是只记住开头和末尾”。更准确的描述是：模型的有效上下文利用受到位置、相对长度、结构和干扰的共同影响。

输入较短时，首因和近因共同作用，容易形成 U 形；输入接近上下文窗口上限时，首因优势可能衰减，曲线变成偏向输入末尾的距离效应。简单字面检索可能表现接近完美，但无字面重合、结构化干扰和多跳推理仍会暴露明显退化。

## 一、问题是否仍然存在

### 奠基证据

[Lost in the Middle](https://www.alphaxiv.org/abs/2307.03172) 用位置可控的多文档问答和键值检索系统展示：相同相关信息位于输入开头或末尾时通常优于位于中间。它证明的是位置相关的利用能力，而不是中间 Token 被物理删除。

[RULER](https://www.alphaxiv.org/abs/2404.06654) 进一步表明，模型声明的上下文窗口通常高于任务相关的有效上下文长度。RULER 很适合测试长度与任务复杂度，但不同子任务不应全部解释为固定 U 形。

[LongBench](https://www.alphaxiv.org/abs/2308.14508) 提供多任务长上下文评测，证明真实任务中的长程理解仍然困难；由于它不是严格的位置控制实验，不能单独作为 U 形位置偏差的直接因果证据。

### 去掉字面匹配之后

[NoLiMa](https://www.alphaxiv.org/abs/2502.05167) 尽量消除 query 与目标证据之间的字面重合。在 13 个声明支持至少 128K 的模型中，11 个在 32K 上下降到其短上下文基线的 50% 以下。该结果说明普通 needle 测试可能严重高估有效上下文能力。

### U 形不是固定形态

[Positional Biases Shift as Inputs Approach Context Window Limits](https://www.alphaxiv.org/abs/2508.07479) 将输入长度除以模型最大窗口，得到相对长度。六个模型的实验显示：

- 相对长度不超过约 0.5 时，Lost-in-the-Middle 最明显；
- 继续增加长度时，开头位置准确率下降，末尾优势保持；
- 接近窗口上限时，典型 U 形可能消失，转为 `last > middle > first` 的距离偏置；
- 当检索成功时，推理的位置曲线显著变平，说明推理偏差很大程度由检索失败传导。

因此，“没有观察到 U 形”不代表问题消失，也可能是开头退化到了中间水平。

### 2026 年证据

[Self-Consistency Falls Short](https://www.alphaxiv.org/abs/2411.01101) 在 8 个模型、9 类任务和大量长上下文实验中发现位置偏差持续存在，并随长度增加或模型缩小而恶化。多次采样投票并不能纠正系统性位置错误，反而可能放大相关错误。该工作已发表于 TACL 2026，但所测模型主要来自 2024–2025 代际，并非所有最新闭源模型。

[Attention Basin](https://www.alphaxiv.org/abs/2508.05128) 在包括 Qwen3 变体在内的多种模型上发现，按文档或示例组织的结构化块会形成块级 U 形注意力分布。移除标点、大小写和文档分隔符后，注意力盆地显著减弱，剩下更强的近因偏置。这说明结构边界是重要因素，Attention Sink 不是唯一解释。该工作已被 ACL 2026 接收。

[Positional Failures in Long-Context LLMs](https://www.alphaxiv.org/abs/2605.23170) 使用 CRE 框架同时控制任务位置、filler 和长度。在论文所调用的 DeepSeek-V4-Pro、MiMo-V2.5-Pro、Kimi-K2.6、GLM-5.1 API 上：

- `with_solutions` filler 下，新模型相对旧代明显改善；64K 时三个模型的中间位置与末尾位置在 ±6 个百分点内，MiMo-V2.5-Pro 仍下降 32 个百分点；
- `questions_only_v2` filler 下，四个模型在 8K、32K、64K 均存在中间下降，范围为 16–56 个百分点；
- 中性文本通常影响很小，但个别模型会随长度出现明显下降；
- 初始五模型中，76% 的中间位置错误匹配某个 filler 答案，而末尾位置只有 22%。

这是直接涉及 2026 模型标识的重要结果，但仍是预印本：每条件样本数为 50，多数 64K 结果只有一个种子，不同厂商 API 还引入了推理栈差异。因此应视为强烈预警，而不是最终排行榜。

## 二、可能机制

### 因果掩码与近因效应

自回归生成时 query 通常位于输入末尾。靠近末尾的信息具有更短的交互距离，而早期信息必须经过更长的表示和注意力路径。

### Attention Sink 与首因效应

[Attention Sinks](https://www.alphaxiv.org/abs/2309.17453) 发现开头 Token 会吸收异常注意力，对流式推理稳定性很重要。它为首因偏置提供了机制线索，但原论文并未证明 Attention Sink 是所有行为层 Lost-in-the-Middle 的唯一原因。

### RoPE 衰减与位置波动

不同 RoPE 频率和层可能产生位置相关的注意力低谷。训练免更新的多尺度 RoPE、逐层 scaling 和隐藏通道校准能够改善部分位置，支持位置编码参与了该问题，但也不能排除训练数据和任务结构因素。

### 结构边界和注意力盆地

标题、换行、文档分隔符和 few-shot 示例边界会让模型形成块级位置先验。该效应可以与 Token 级 attention sink、近因效应同时存在。

### 干扰竞争

当 filler 与目标具有相同问题格式、领域或候选答案时，模型可能检索到错误实例。此时失败不是“看不到任何内容”，而是目标证据在竞争中失去优势。

### 共线线索与归因不可识别性

[Shortcut Before Circuit](https://www.alphaxiv.org/abs/2608.24460) 在 26M 参数合成 Transformer 中让“取最新值”和“取最稀有值”在训练文档上严格选择同一答案，再用保持真值、Token 数和答案位置不变的最小编辑把两条线索拆开。75 个训练运行的 held-in accuracy 均至少为 0.999，但干预后的规则读出在三 seed 间并不稳定：25 个配置中有 13 个的符号比例差超过 0.3。它研究的是小模型合成预训练中的机制选择，不是本项目 7B 长上下文适配的效果基线；其直接启示是，只看近满分行为无法区分共线训练因素，必须在数据设计中主动拆开位置、重复和目标内容，并把独立训练 seed 而非文档行数作为复制单位。

### 初始化结构假设

[Lost at Birth](https://www.alphaxiv.org/abs/2603.10123) 从初始化 Transformer 的因果掩码、残差和 Value 路径推导 U 形输入输出 Jacobian。该结果提示结构先验可能在训练前已经存在，但它是 2026 年单篇预印本，理论主要覆盖初始化和受限路径，尚不能视为完整机制或“不可能通过训练覆盖”的证明。

## 三、已有缓解方向

### 位置均衡监督训练

[IN2/FILM](https://www.alphaxiv.org/abs/2404.16811) 使用细粒度位置探测和跨片段信息整合数据训练模型。实验中，Mistral 主干的位置最大—最小差距从约 56.2 缩小到 13.9，同时 MMLU 基本保持。这支持“答案必须依赖不同位置证据”的训练比单纯增加长文本更有效。

### 位置蒸馏

[Pos2Distill](https://www.alphaxiv.org/abs/2508.15709) 把同一证据放在优势位置生成教师分布，再蒸馏到中间或其他弱势位置。在 8K 检索中，位置差距可从 17.8 缩小到 3.0；部分键值检索从 55.2% 提升到 96.9%。它直接针对跨位置不变性，但专门化的检索与推理蒸馏仍在各自任务内最强。

它也是本项目最接近、必须正面区分的训练先例：Pos2Distill 同时引入“同一样本跨位置出现”、优势位置到劣势位置的非对称教师方向、KL 或 CoT 蒸馏目标，因而无法单独归因跨位置身份配对本身。本项目不声称首次复用同一事实的不同位置，而是用等事实曝光、等序列、等 prompt Token 的 `independent vs paired` 因子，再与三种普通 completion 监督正交组合，检验不用教师分布时配对是否仍有独立作用。

### 位置索引扰动与长度课程

[Shuffle the Context](https://www.alphaxiv.org/abs/2604.14339) 对同一长序列做标准 RoPE 索引和跳跃/循环扰动索引两次前向，用 stop-gradient reverse KL 让扰动视图贴近标准视图。它在 Llama-3-8B 与 Qwen-3-4B 上使用 ProLong 长语料，覆盖 RULER、HELMET、后续 SFT 的 LongBench-v2、超训练窗口长度外推和短任务回归；论文还用延长普通训练步数做墙钟匹配。该方法同时改变位置编码暴露、双前向目标和训练算力，回答的是“显式索引不变性正则是否有效”，并不能单独分离同一事实跨位置配对或监督内容。本项目保持 RoPE 与普通 completion-only 目标不变，因而是互补的窄归因实验，而不是对其效果的直接复现。

[Randomized YaRN](https://www.alphaxiv.org/abs/2606.23687) 在小于 8K 的 LoRA 训练序列上，从逐渐扩大的位置范围无放回采样并排序 YaRN 索引，使 Token 顺序不变但提前接触远长于训练序列的位置编码。它用 Qwen2.5-7B 和 OLMo3-7B 在 BABILong QA3 与 MRCR 上评测到 128K，并通过去掉长度课程、普通 LoRA、固定 YaRN 和无 YaRN 的随机索引控制显示课程与位置随机化均重要。它直接研究未见长度外推；本项目的 1K/8K/32K 评测则在固定模型窗口和位置机制下研究监督构造的 OOD 迁移，两者的“位置泛化”定义不能混写。

### 证据图数据合成

[LongCrafter](https://www.alphaxiv.org/abs/2607.06160) 用证据图、任务类型控制和显式引用构造 2,000 条长上下文 SFT 数据。在 Qwen2.5-7B 和 Llama-3.1-8B 上，综合长上下文评测比第二名 SFT 基线高约 5 分，并在 20 个候选文档的位置探测中保持近乎平坦的高准确率。其限制是预印本、模型规模较小，且位置探测偏向单正确文档检索。

### 训练时强化上下文表示

[FocuSFT](https://www.alphaxiv.org/abs/2605.09932) 用双层优化让临时 LoRA 先适应当前上下文，再监督正式模型。它相对普通 SFT 在 4K–32K BABILong 上提升约 9.6–14.2 个百分点，但只测试了 Qwen2.5-7B，也未完整报告位置控制曲线。

原文进一步报告训练墙钟为普通 SFT 的 1.71 倍、推理成本不变，RULER 16K 的 CWE aggregation 从 72.9% 提升到 81.1%，并明确把单模型家族和固定 3,000 条训练语料列为限制。它改变双层优化和 context token 的双向注意力；本项目保持普通 completion-only QLoRA 与因果推理模板不变，因此比较的是更窄的数据构造归因问题。

[EXACT](https://www.alphaxiv.org/abs/2605.10544) 指出 packed causal LM 中名义序列长度不等于每个目标 Token 实际获得的同文档左上下文长度。它保持训练流、Token 预算、优化器和后续 QA-SFT 不变，只给长有效上下文尾部增加按逆频率分配的 loss 权重；七个 Qwen/LLaMA 配置的 NoLiMa 与 RULER 主表均改善，并用随机同质量权重、绝对 packed-position 权重、统一长尾权重等消融定位了有效上下文变量。该工作与本项目互补：它研究 CPT 的 Token 级 loss 分配，本项目研究 completion-only SFT 中“同一事实是否显式跨位置配对”以及答案、证据 ID、精确引用三种监督内容。

### 推理期或位置编码校准

[Found in the Middle](https://www.alphaxiv.org/abs/2406.16008) 先把固定上下文移动到不同位置，估计与内容无关的 U 形注意力基线，再校准文档注意力；它在 NaturalQuestions 与 SynthWiki 的 10/20 文档 RAG 上最高提升约 15 个百分点，但每个位置需要额外前向，整体为 $O(K)$ 次额外模型调用，且论文明确未定位注意力偏差的根因。[LPES](https://www.alphaxiv.org/abs/2606.27705) 用 200 个样本和 Bézier 约束遗传搜索，为不同层选择 RoPE scaling；搜索完成后不更新模型权重、推理只需单次前向，键值检索最高提升 11.2 个百分点。其公开搜索成本约为 4 张 H100 上 3--4 小时；主要实验集中在 7B 模型和不超过 16K 的长任务，且论文明确没有评测训练/微调场景。两者与本项目是机制互补关系，而不是同一消融轴：它们改变推理期注意力或位置编码，本项目固定模型机制，检验训练样本的跨位置身份配对和 completion 监督内容。

## 四、对早期总结的修订

1. “中间信息遗忘”应改为“位置相关的检索和利用失败”。
2. U 形是常见曲线，不是跨长度、模型和任务不变的定律。
3. Attention Sink 是机制线索之一，不应当作唯一因果解释。
4. LongBench 支持长上下文任务困难，但不是严格的位置控制证据。
5. LongAlign 证明长指令数据和高效训练策略有效，不直接证明均匀关键位置能够消除 U 形。
6. Data Engineering for 128K 主要证明持续预训练和数据工程能够延长上下文，不等同于复杂中间推理已解决。
7. “Transformer 结构决定无法解决”过强；当前证据只支持存在结构先验和跨分布泛化仍未解决。

## 五、研究空白

- 最新闭源模型缺少公开、可复现的位置控制评测。
- 许多方法只测试单跳检索，没有同时覆盖无字面重合、多跳、长顺序依赖和代码任务。
- 论文常报告平均准确率，没有报告最弱位置和跨位置方差。
- 直接针对位置鲁棒性的强化学习证据少于 SFT 和蒸馏。
- 尚不清楚位置鲁棒性从 8K/16K 向 64K/128K 的外推规律。
- SSM、线性注意力和稀疏注意力是否比标准 Transformer 更位置稳健，仍需要统一协议比较。
