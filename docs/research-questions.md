# 研究问题与边界

## 核心问题

### RQ1：位置偏差在 2026 年模型中是否仍然存在？

对同一个上下文和问题，只改变证据的绝对位置与相对位置，测量答案准确率、证据定位率和推理成功率是否显著变化。

### RQ2：位置曲线由哪些变量决定？

重点考察：

- 输入长度与模型窗口的比值；
- 证据到 query 的距离；
- 单证据与多证据；
- 文档分隔符和结构边界；
- filler 与目标任务的语义、格式及答案重合程度；
- 字面检索、语义检索、顺序推理和多跳推理；
- query 位于开头、末尾或独立对话轮次。

### RQ3：失败发生在检索阶段还是推理阶段？

将任务拆成两个最小配对步骤：

1. 要求模型指出证据及其文档编号；
2. 在证据已知或直接提供的条件下完成推理。

若证据提供后位置差异基本消失，主要瓶颈是检索；若仍然存在，则还包含整合或推理阶段的偏差。

### RQ4：针对性训练能否获得跨位置泛化？

比较普通长上下文 SFT、位置均衡 SFT、位置蒸馏、证据引用监督和最差位置优化，观察训练位置之外以及未见长度上的表现。

### RQ5：强化学习是否优于监督学习？

在相同数据和计算预算下，比较：

- 位置均衡 SFT；
- SFT 加跨位置 KL 一致性；
- SFT 后进行位置分组强化学习；
- 仅优化平均奖励与优化最差位置/CVaR 奖励。

### RQ6：训练修复与推理期修复能否叠加？

比较模型训练、RoPE 校准、文档重排、检索压缩和分层摘要的单独收益及组合收益。

## 工作假设

| 编号 | 假设 | 可证伪观察 |
|---|---|---|
| H1 | U 形强度主要取决于输入占窗口的相对比例，而非绝对 Token 数 | 不同窗口模型在相同比例下仍无一致趋势 |
| H2 | 结构化、高相似度 filler 比中性文本产生更强的位置失败 | 三种 filler 下的曲线无显著差异 |
| H3 | 多数推理位置偏差由证据检索失败传导 | 提供正确证据后位置差距仍保持不变 |
| H4 | 同一样本的跨位置配对训练比单纯增加长文本更有效 | 在相同 Token 预算下没有优势 |
| H5 | 优化平均准确率不足以修复最弱位置 | 平均奖励训练同时稳定消除位置 gap |
| H6 | 证据引用监督能降低 filler 抢答和虚假检索 | 引用监督不改变证据定位率或错误来源 |
| H7 | 位置鲁棒性不会自动迁移到更长长度和更复杂任务 | 简单检索训练可零样本消除长程多跳位置差异 |

## 不在当前阶段直接声称的内容

- 不把注意力权重直接等同于因果解释或模型“真正关注”。
- 不从单一 Needle-in-a-Haystack 结果推断真实长文档理解能力。
- 不从一个 7B 模型或一个长度外推全部 2026 模型。
- 不把上下文窗口可接受输入等同于可靠有效上下文。
- 不把某个 benchmark 上曲线变平等同于位置偏差已普遍根治。
